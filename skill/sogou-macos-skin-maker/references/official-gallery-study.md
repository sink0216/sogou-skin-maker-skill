# Official gallery case-study method

Use this reference when the user asks to learn from official Sogou skins, requests inspiration, or has not chosen a strong visual direction.

## Sources and scope

- Start with the current [Sogou skin gallery](https://pinyin.sogou.com/skins/).
- Use Sogou's official design/tutorial pages for layout, contrast, preview, and stretching principles.
- Treat gallery artwork as case-study material, not reusable production art. Do not download, trace, redistribute, or closely imitate third-party/IP assets without authorization.
- Many gallery cases and official tutorials describe Windows `.ssf` skins. Extract only transferable design grammar, then implement it in the user's selected platform format using a verified local base and runtime behavior. Do not translate Windows structure into macOS or vice versa without an explicit format map.

## Sampling

Sample 6–12 cases across at least three relevant groups rather than choosing one attractive skin. The official gallery exposes broad directions such as minimalist, cartoon/animation, still-life/scenery, fashionable/material, games, film/TV, sports, branded/IP, and color/tag collections.

For each case, record:

| Field | Question |
|---|---|
| Source | What official page and skin title were studied? |
| Theme type | Character, object, brand/IP, scene, pattern, or minimal/material? |
| Bar archetype | Compact attached subject, object-shaped bar, scene strip, framed panel, or minimal capsule? |
| Hierarchy | What is noticed first, second, and third? |
| Subject anchor | Left, right, above, below, crossing, background, or absent? |
| Text protection | How are input and candidates kept readable? |
| Fixed/stretch zones | Which details must stay fixed, and where is a safe flat stretch region? |
| Palette/material | Flat, translucent, textured, outlined, glossy, hand-painted, pixel, etc.? |
| Ornament density | Sparse, clustered at caps, repeated pattern, or scene-wide? |
| Transferable rule | What abstract principle fits the user's brief? |
| Do not copy | Which identity-specific artwork or branding must not transfer? |

## Synthesis

Propose 1–3 directions using only transferable rules. A direction must state:

- theme type and hierarchy;
- candidate-bar silhouette and layer count;
- subject and ornament anchors;
- fixed-cap and stretch-safe zones;
- palette, material, line, and texture system;
- selected-candidate treatment;
- optional motion concept;
- selected-platform runtime risks.

Do not present a collage of unrelated popular motifs. One coherent art system is more important than the number of decorations.

## Official principles to retain

The official advanced tutorial emphasizes:

- multiple valid input-window layouts and subject placements;
- keeping main imagery toward the sides so it does not cover input or candidates;
- sufficient contrast between text and background;
- detail and hierarchy for both minimal and richly illustrated designs;
- showing the skin clearly in preview imagery;
- testing long candidate strings, not only 3–5 candidates;
- selecting a stretch region without core imagery to prevent deformation.

Treat these as design heuristics. Real screenshots from the selected installed Sogou client remain the authority for dimensions, anchors, control occupancy, and font metrics.
